# Eigene Workouts

Hier `.zwo` (Zwift), `.mrc` (ErgDB/TrainerDay/GoldenCheetah) oder `.erg`-Dateien (mit `FTP =` im Kopf) ablegen.

Liegt eine Datei in einem Unterordner, dessen Name einer Kategorie entspricht
(`Regeneration`, `Ausdauer`, `Tempo`, `Sweet Spot`, `Schwelle`, `VO2max`, `Tests`),
erscheint sie in dieser Kategorie, sonst unter „Eigene“.
Neue Dateien werden beim nächsten Programmstart eingelesen.
